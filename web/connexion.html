Facultatif. Demandé une seule fois sur chaque appareil.
Le téléphone n'arrive pas à ouvrir la page ?

1. Vérifie que le téléphone est sur le même Wi-Fi que ce PC (pas en 4G/5G).
2. La première fois, Windows demande d'autoriser l'application dans le pare-feu : clique « Autoriser ». Si tu as fermé la fenêtre trop vite, clique ci-dessous (Windows demandera ton accord).
3. Le Wi-Fi « invité » de certaines box isole les appareils : utilise le Wi-Fi principal.
